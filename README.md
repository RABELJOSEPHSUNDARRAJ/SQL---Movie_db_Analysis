# 🎬 Movies Database Analysis

This project is designed to demonstrate **SQL database creation, data insertion, and querying** using a Movies Database. It includes movie-related information and various SQL operations to retrieve and analyze the data.

## 📂 Project Files

* **Create & Insert SQL** – Creates the database tables and inserts movie data.
* **SQL Queries** – Contains queries using `SELECT`, `WHERE`, `ORDER BY`, and aggregate functions.
* **JOIN Queries** – Demonstrates how to combine data from multiple tables using SQL JOINs.

## 🛠️ Skills Used

* SQL
* Data Definition and Data Manipulation
* Filtering and Sorting
* Aggregate Functions
* JOIN Operations

This project helps demonstrate fundamental SQL skills for working with relational databases.
